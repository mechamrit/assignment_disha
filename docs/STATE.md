Notes:
- The API refuses to score an answer with no vocabulary words (VALIDATION) and records a CHATTER event instead, so a stray "hmm" can never end a game. The bot is expected to filter these first.
- The idempotency key is derived server-side from roundId and attemptSeq; a mismatched Idempotency-Key header is rejected rather than trusted.
- Prisma is pinned to 6.19.3 and nestjs-pino to 4.6.1 with pino 9, because their newest releases require Node 22.
- A fresh clone needs `npm run db:generate -w api` before typecheck, tests, or build.
- Outside production the API loads api/.env at startup, so `make api-dev`, the OpenAPI emitter, and the e2e suites need no exported variables.
- Root package.json overrides fastify to 5.12.4 (GHSA-w2qp-rph6-63g4, GHSA-3m5p-2c4r-xxw2, fixed in 5.12.1).
- The allow list in .claude/settings.json is narrower than the sketch in docs/PLAN.md: `curl -s http://localhost*` and `uv run *` both match commands that reach other hosts or run any program.
- Node 20 is past end of life (April 2026). The plan pins it; Vite 8 and ESLint 10 need 20.19 or newer.
